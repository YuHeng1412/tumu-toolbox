# 土木学生工具箱

一个**免安装**的网页计算工具，给土木 / 水利 / 交通专业的学生用。打开网页就能算，不用装软件、不用注册。

**在线使用：** https://yuheng1412.github.io/tumu-toolbox/

---

## 已有功能

| 模块 | 说明 |
|---|---|
| 单位换算 | 长度、力、压强、面积、体积、质量、流量、角度，共 8 类 |
| 钢筋理论重量 | 按 `0.00617 × d²` 算单位重量、指定长度总重、1 吨约合长度，附常用直径速查表 |
| 坐标方位角 | 两点坐标 → 水平距离 + 方位角（十进制度 / 度分秒），遵循测量坐标系 x 指北、y 指东的约定 |

## 设计特点

- **零安装**：单个 HTML 文件，双击即用，也可直接部署为静态站点
- **模块化**：新增功能只需在 `MODULES` 数组里加一个对象，不改动已有代码
- **数据自校验**：钢筋重量速查表由同一公式实时生成，表格与计算结果不会出现不一致

## 为什么做这个

专业里大量计算依赖手算和翻表，重复且容易出错。想把它做成随手可用、并且能随着课程推进持续增加模块的工具。
